# Variant Card - Olive Branch Bakes

These are the pricing and limit rules I use for my project.

| Rule | Value |
|------|-------|
| Discount | 10% off the order subtotal when the subtotal is 50.00 or more |
| Quantity limit | 1 to 50 of one item in one order (same as VR-4) |
| Operations limit | at most 10 orders for the same pickup day (Olivia's baking capacity) |
| Prices | taken from the seed menu |
| Rounding | money is rounded to 2 decimal places |

## Notes

- The discount is on the subtotal of the whole order, not on one item.
- Exactly 50.00 gets the discount. 49.99 does not.
- The 11th order for the same pickup day is not accepted.
- Order totals are only for the baker to read. There is no online payment.
